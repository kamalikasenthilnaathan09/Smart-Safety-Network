# 🚨 Smart Safety Network

A simple web-based personal safety application developed using HTML, CSS, and JavaScript.

## Features
- 🚨 SOS Emergency Button
- 📍 Live GPS Location
- 🗺️ Google Maps Integration
- 📞 Emergency Contact Buttons
- 🎤 Tamil Voice Assistant
- 🌐 English & Tamil Language Support
- 🛡️ Nearby Safe Spot Search

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Geolocation API
- Speech Synthesis API
- Google Maps Embed
