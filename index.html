ℹ️ About Smart Safety Network

Smart Safety Network is a web-based personal safety platform designed to help users during emergency situations. It provides fast access to SOS alerts, location tracking, emergency calling, safe spot search, and voice guidance. The system is simple enough for students, working people, elderly users, and beginners. It supports Tamil and English, making it easier for local users to understand instructions quickly. This project uses HTML, CSS, JavaScript, browser GPS, speech synthesis, and map embedding to create a smart safety experience in a simple website format.

❓ Frequently Asked Questions

1. What is this website for?It helps users in emergency situations using SOS, GPS, and quick actions.
2. Does it show live location?Yes, it gets your current location from the browser GPS.
3. Can it call emergency services?Yes, the Call 112 button opens the dial option on supported devices.
4. Does it support Tamil?Yes, the interface supports Tamil and includes Tamil voice assistance.
5. Does it store my data?No, this demo works in the browser and does not save data permanently.
